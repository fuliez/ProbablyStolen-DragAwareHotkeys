# Workshop cover requirements

- Original illustration, 1024 × 1024 PNG or JPEG, under 1 MB; readable at 200 × 200.
- Dark space/pawnshop palette with a bright item silhouette held by a cursor; curved Q/E arrows around it. Show a closed storage box with a small blocked-hotkey symbol.
- Main title: **Drag-Aware Hotkeys**. Chinese subtitle: **解决拖拽时按键冲突**.
- High contrast, generous margins; avoid tiny technical text, version numbers, official logos or claims of developer endorsement.
- Use only original or properly licensed art/fonts. Do not copy the reference mods' covers or redistribute game artwork.
- Keep the source design outside runtime packages. Supply workshop/cover.jpg through `-PreviewFile` for the Steam page. The same decoded image is also shipped as mod/preview.png at the runtime root for local and fallback in-game display.
- `cover.jpg` is the selected original AI-generated illustration, prepared at 1024 × 1024 and approximately 313 KiB. English/Chinese typography and composition were visually reviewed. It contains no game artwork. The original full-size generation stays in local AI output storage; this repository contains the upload-ready cover. See ARTWORK.md for provenance and licensing scope.
